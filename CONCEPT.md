# CityBoost — Городской портал заявок

> **Версия:** 1.0.0 | **Статус:** ✅ Завершён

---

## Что это такое

**CityBoost** — это веб-платформа для подачи и обработки городских заявок от жителей. Аналог порталов «Добродел» или «Наш город».

Жители могут сообщать о городских проблемах: ямы на дорогах, сломанные скамейки, мусор, неработающие фонари, разбитые тротуары и любые другие вопросы благоустройства. Администраторы муниципалитета видят все заявки, назначают ответственных, меняют статусы и отслеживают ход выполнения.

Проект состоит из **бэкенда** (FastAPI + PostgreSQL) и **фронтенда** (Vue 3), развёрнутых через Docker.

## Ключевые возможности

### 👤 Для жителей (пользователей)

| Возможность | Описание |
|-------------|----------|
| **Регистрация** | Создать аккаунт по email (валидация пароля: 8+ символов, заглавная + строчная + цифра) |
| **Вход в систему** | По email и паролю, с JWT access + refresh токенами и автоматической ротацией |
| **Восстановление пароля** | Забыли пароль? Запрос на сброс → письмо на почту со ссылкой (срок действия — 1 час) |
| **Личный кабинет** | Просмотр и редактирование профиля (имя, email, смена пароля) |
| **Создание заявки** | Заголовок, подробное описание, одно или несколько фото (JPEG/PNG), местоположение на карте |
| **Мои заявки** | Лента всех своих заявок с пагинацией и фильтром по статусу |
| **Детали заявки** | Просмотр фото, статуса, комментариев администратора, истории изменений |
| **Загрузка файлов** | Добавление дополнительных фото к уже созданной заявке (до 10 МБ, до 5 файлов) |
| **Комментарии** | Обсуждение заявки с администратором |
| **Статистика** | Сколько заявок подано, сколько в работе, сколько выполнено |

### ⚙️ Для администраторов

| Возможность | Описание |
|-------------|----------|
| **Все заявки** | Лента всех заявок от всех жителей с фильтрацией по статусу и датам |
| **Изменение статуса** | Перевод заявки по цепочке: **Новая** → **В работе** → **Выполнена** → **Закрыта** |
| **Назначение ответственного** | Взятие заявки в работу (assigned_to) |
| **Комментарии** | Добавление комментариев к заявкам |
| **История заявки** | Лента всех изменений статуса с указанием, кто и когда изменил |
| **Управление пользователями** | Список всех пользователей, поиск по имени/email, фильтры (заблокированные, по роли) |
| **Смена ролей** | Повышение пользователя до администратора или понижение обратно |
| **Блокировка/разблокировка** | Баннарушение — аккаунт блокируется и не может войти в систему |
| **Аудит-лог** | Журнал всех действий администраторов (кто, когда, что сделал) |
| **Статистика пользователей** | Сколько всего пользователей, админов, заблокированных |

### 🛡️ Безопасность

| Механизм | Описание |
|----------|----------|
| **JWT-аутентификация** | Access token (1 час) + Refresh token (7 дней) с HMAC-SHA256 |
| **Refresh token ротация** | При каждом обновлении старый токен аннулируется — защита от кражи |
| **Rate limiting** | 3 регистрации/час, 10 попыток входа/мин, 30 запросов к заявкам/мин (через Redis) |
| **Brute-force защита** | 5 неудачных попыток входа → блокировка IP на 15 минут |
| **Security headers** | X-Content-Type-Options, X-Frame-Options, Referrer-Policy, Permissions-Policy |
| **CORS** | Ограничен localhost (не открыт для всех) |
| **Валидация файлов** | Проверка по magic bytes файла, не доверяем MIME-типу из заголовков |
| **Политика паролей** | Минимум 8 символов, обязательны заглавная/строчная/цифра, чёрный список простых паролей |
| **Защита от самоблокировки** | Администратор не может заблокировать или понизить сам себя |

### 📍 Геопозиционирование

Заявки привязываются к месту на карте:

- **Интерактивная карта** (OpenStreetMap + Leaflet) — выбор точки на карте при создании заявки
- **Автоопределение адреса** — по координатам через Nominatim (OpenStreetMap)
- **Автоопределение координат** — по текстовому адресу
- **Фоновый геокодер** — если сервис временно недоступен, адрес или координаты дозапрашиваются в фоне (arq worker) с экспоненциальной задержкой до 5 попыток

### 🎨 Интерфейс

- **Адаптивный дизайн** — работает на телефонах, планшетах и десктопах (Tailwind CSS)
- **Тёмная тема** — автоматически подстраивается под системные настройки или выбирается вручную
- **Интерактивная карта** — выбор местоположения на карте OSM
- **Пагинация** — постраничная навигация по спискам
- **Loading skeletons** — плавная загрузка контента
- **Image lightbox** — просмотр фото в полноэкранном режиме
- **Toast-уведомления** — всплывающие сообщения об успехе/ошибке
- **Страницы 404 и ошибок** — понятные страницы при проблемах

### 📧 Email-уведомления

- **Сброс пароля** — письмо со ссылкой для восстановления (стильный HTML-шаблон)
- SMTP-сервис с поддержкой TLS, асинхронная отправка

## Статусы заявок (жизненный цикл)

```
Новая (NEW)
    │
    ▼
В работе (IN_WORK) — администратор взял в работу
    │
    ▼
Выполнена (DONE) — проблема решена
    │
    ▼
Закрыта (CLOSED) — житель подтвердил / архивировано
```

Каждое изменение статуса логируется в **историю изменений** — видно, кто и когда изменил статус.

## Технический стек

### Бэкенд
- **Python 3.14** + FastAPI (async)
- **SQLAlchemy 2.0** (async) + asyncpg
- **PostgreSQL 16** — основная БД
- **Redis 7** — rate limiting, брутфорс-защита, фоновые задачи
- **JWT** (python-jose, HS256) — аутентификация
- **Alembic** — миграции БД
- **arq** — фоновый воркер (геокодирование)
- **Pillow** — работа с изображениями

### Фронтенд
- **Vue 3** (Composition API, TypeScript)
- **Pinia** — управление состоянием
- **Vue Router 4** — навигация (hash-based)
- **Tailwind CSS 3** — стилизация
- **Axios** — HTTP-клиент с JWT-интерцепторами
- **Leaflet 1.9.4** — карты (OSM)

### Инфраструктура (Docker)
| Сервис | Роль |
|--------|------|
| `backend` | FastAPI-приложение (порт 8000) |
| `worker` | arq-воркер фоновых задач |
| `db` | PostgreSQL 16 |
| `redis` | Redis 7 |
| `nginx` | Reverse proxy + раздача статики (порт 80/443) |
| `certbot` | SSL-сертификаты Let's Encrypt |
